Corpus for the Howard Marks persona. Primary voice/framework source is his Oaktree
memo archive (1990-2026), all `type: author` (solo-written essays; not tagged
per-entry since the whole `## Articles` section is memos). Spoken-voice sources
are tagged below per Phase 0 voice-safety rules. Oaktree's memo pages carry an
explicit "may not be copied, reproduced, republished, or posted in whole or in
part" notice, so `content/articles/*.md` entries are original analytical
summaries with short (1-3 sentence) attributed quotations, not full-text
reproductions. Full-text-available entries (2022-2026 memos, where the memo
page renders inline HTML) are marked accordingly in `notes:`; older memos
(pre-2022, PDF-only pages) are reconstructed from Oaktree's own "Best of" memo
descriptions plus this same author's direct self-citation of the older memo in
a newer one already in this corpus, with source attribution kept explicit in
each file.
